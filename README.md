# Найди лишний — мультиплеерная версия

## Что нужно
- Компьютер с установленным Node.js (рекомендуется LTS).
- Интернет нужен только для установки библиотек; для запуска на одном компьютере игра может работать локально.

## Запуск на Windows
1. Установи Node.js LTS с https://nodejs.org/
2. Распакуй архив в отдельную папку.
3. Открой эту папку в Проводнике.
4. В адресной строке Проводника напиши `cmd` и нажми Enter.
5. В открывшемся окне выполни:

   ```bash
   npm install
   npm start
   ```

6. Открой в браузере http://localhost:3000

## Запуск на macOS / Linux
Открой терминал в распакованной папке и выполни:

```bash
npm install
npm start
```

Затем открой http://localhost:3000

## Как проверить
1. Открой игру в одном окне браузера и создай комнату.
2. Открой http://localhost:3000 во втором окне или в режиме инкогнито.
3. Введи код комнаты и присоединись.
4. Создатель нажимает «Начать матч».
5. Оба игрока видят один и тот же раунд. Первый правильный ответ получает очко и запускает следующий раунд. Ошибка заканчивает матч в пользу соперника. Первый игрок, набравший 10 очков, выигрывает.

## Важно про игру с другом через интернет
`localhost` доступен только на том компьютере, где запущен сервер. Чтобы друг подключился из другого дома, сервер нужно развернуть на хостинге, который поддерживает Node.js и WebSocket/Socket.IO. Не публикуй личный компьютер в интернет через открытие портов, если не понимаешь настройки безопасности.

## Файлы
- `server.js` — сервер, комнаты и правила матча.
- `public/index.html` — интерфейс игры в браузере.
- `package.json` — список зависимостей и команда запуска.
